Общий лимит за сутки

{% if daily_total.limit %} потрачено сегодня: {{ '%.0f'|format(daily_total.spent|float) }}, осталось {{ '%.0f'|format(daily_total.remaining|float) }} {% endif %}
Считается по фактическим покупкам за сутки UTC. Останавливает торговлю, даже если бюджет стратегии ещё не исчерпан — это предохранитель от слишком быстрого расхода. Срабатывает более строгий из двух лимитов: общего и по площадке.

Автономный режим для приватных площадок

У этих площадок нет публичного API и обязательств по доступности: эндпоинт может смениться без предупреждения, а аккаунт — быть заблокирован. В режиме AUTO между такой ошибкой и вашими деньгами не будет человека. Включайте только после серии успешных сделок с подтверждением.

Курсы валют

Разница цен между площадками

Один и тот же подарок стоит на площадках по-разному. Бот показывает связки, которые переживают обе комиссии, перенос подарка и курс. Автоматически такие сделки не исполняются: между покупкой и продажей подарок нужно перевести вручную, и за это время цена на второй площадке может уйти. Найденное появляется на странице «Кандидаты».
